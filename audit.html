Data audit

Every number used on the site, with its official source, period, verification status and the independent check it passed. Figures that failed a check, or that came only from news/AI, never feed a call.

Verification runs automatically in GitHub Actions on every refresh: each dataset is re-downloaded from the official page and checked against a second, independent figure. If a check fails, the run fails and the last good values are kept.
