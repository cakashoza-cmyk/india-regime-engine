      Scoring method (study this to distrust the machine)

      1. Dial scores

      • Growth: among indicators with a known direction, if ≥60% rising → Rising; ≥60% falling → Falling; else Unclear. Indicators with Unknown direction are skipped (not counted as votes).
      • Inflation: same majority on CPI headline/core/food + crude + INR weakness (INR/USD rising = weaker INR = inflationary). If crude/food rising but core flat/falling → Transitory.
      • Liquidity: RBI stance (hiking/tightening = contracting; cutting/easing = expanding), rising US/India yields = contracting, rising DXY or weaker INR = contracting, FII selling = contracting. Majority rules; Unclear if thin data.

      2. Quadrant map

      • Rising + Falling inflation → Goldilocks → Risk-On
      • Rising + Rising inflation → Reflation → Cyclicals / banks / commodities
      • Falling + Falling inflation → Slowdown → Staples / defensives / bonds
      • Falling + Rising inflation → Stagflation → Risk-Off (cash / gold)

      3. Liquidity overlay

      Expanding amplifies risk assets. Contracting suppresses — nudges toward defensives / risk-off even in Goldilocks or Reflation.

      4. Final call gate

      If Growth or Inflation is Unclear, or Liquidity is Unclear and the quadrant is borderline, or dials conflict with no majority path → Unclear / wait. No forced buy list.
