# Regime overlay, margin driver, stress panel (2 Nov 2026, economist audit fixes 1-4)
Code only, no AI calls. Inputs: RBI repo + stance, Brent, USD/INR (1-yr change, market data cross-checked within 2% against the RBI reference rate), MoSPI CPI, OEA WPI / Output PPI / trial Input PPI press release (base 2022-23, NIC-2 groups). Missing or failed inputs switch the factor/driver off; nothing is filled in.

1. **Regime overlay** (`engine/regime_overlay.py`, `engine/sector_sensitivity.json`). Factors: tightening (repo up and stance < 0), oil shock (Brent > $100), weak rupee (USD/INR up > 3% YoY), cost push (WPI − CPI > 3 pp). Late cycle = tightening plus cost push or oil shock. Points = 2.5 × sensitivity notch per active factor, clamped −10..+6. Late cycle caps cyclical sectors at 85. Not applied to proxy (series-misfit) or price-controlled sectors. Sensitivities are analyst judgments with a one-line rationale each; not estimated.
2. **Margin driver**: % change in Output PPI minus % change in trial Input PPI over the months in the release (Apr→latest), same NIC-2 group. ±2 pp → ±1, weight 1.0. Narrow NIC-10 slices (edible oil, tea, cashew, coffee, rice, spices, marine, fruit & veg) are shown but not scored. Unmapped sectors: no driver (unknown). Trial IPPI starts Mar 2026, so no YoY yet.
3. **Stress panel**: Brent +20% = one extra crude notch; rupee −5% = one extra rupee notch; repo +50 bp = two rate notches; demand −5% = re-score with output growth 5 pp lower. Each shock alone. Flips counted on state × sector calls.
4. **Credit gap**: bank credit deflated by the sector's WPI group (headline WPI for MSME/trade books measured against nominal GST, where no deflation is applied since both are nominal). Gap ≤ 15 pp scores 0 (no reward), > 15 pp −1 (watch), > 25 pp −1 and no OK call. Shrinking credit stays −1. A falling GNPA counts +1 only if another driver is positive.
5. **Wrong if / check back**: built from the drivers that moved the call; dates = next MPC, next WPI release (14th, weekend-adjusted), month-end SIBC, IIP on the 28th.
Not back-tested (see sector_backtest.md).
